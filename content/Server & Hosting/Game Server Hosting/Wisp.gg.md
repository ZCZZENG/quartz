[Wisp](wisp.gg) is a hard fork of [Pterodactyl](pterodactyl.io). In my experience, it's nice to have a System "just work" out of the box. BUT having control over (mostly) everything is super important. 

Not being able to change the code base on Wisp is obvious. But you are also missing out on any extensions. 

Theres no way for you to add Translations yourself and with the Devs being very inactive or atleast not communicative at all, it's hard to participate in translating.
