### 拼音类
4. 拼音
    ```
    # 格式检查代码
    import re

    example = "chi拼音：吃(chi)"

    # 使用正则提取前后两个拼音
    pattern = r"^([a-zA-Z]+)拼音：([\u4e00-\u9fa5])\(([a-z]+)\)$"
    match = re.match(pattern, example)

    if match:
        prefix_pinyin = match.group(1)  # 前面的拼音
        bracket_pinyin = match.group(3)  # 括号里的拼音

        if prefix_pinyin.lower() == bracket_pinyin:
            print("✅ 匹配成功，且拼音忽略大小写一致")
        else:
            print("❌ 拼音不同")
    else:
        print("❌ 不符合基本格式")
    ```
chicken
"split": "chi拼音：吃(chi)；c形状：嘴巴；ken拼音：肯(ken)"

8. 拼音首字母
    ```
    # 格式检查代码
    import re

    example = "act拼音首字母：爱(ai)出(chu)台(tai)"

    # 正则表达式
    pattern = r"^([a-zA-Z]+)拼音首字母：(?:([\u4e00-\u9fa5])\(([a-z])[a-z]*\))+$"

    match = re.match(pattern, example)

    prefix_string = match.group(1)
    characters_list = match.captures(2)
    letters_list = match.captures(3)

    if prefix_string != "".join(letters_list):
        print(f"“拼音首字母”格式错误：\n{}")  

    for character in characters_list:
        if character not in memorize:
    ```

# 补充
1. memorize字段中的中文释义的词性要与被记的词性抱持一致
    - 反例：
    ```
    {
        "instruction": "为下面的英文创作巧记思路",
        "input": "quiet n. 安静",
        "output": {
            "English": "quiet",
            "phonetic_symbol": "[ ˈkwaɪət ]",
            "Chinese": "n. 安静",
            "split": "qui拼音似：窥(kui)；et拼音首字母：儿(er)童(tong)",
            "memorize": "嘘！有个恶徒在安静窥视"
        }
    }
    ```
    - 正例：
    ```
    {
        "instruction": "为下面的英文创作巧记思路",
        "input": "quiet adj. 安静的",
        "output": {
            "English": "quiet",
            "phonetic_symbol": "[ ˈkwaɪət ]",
            "Chinese": "n. 安静； adj. 安静的",
            "split": "qui拼音似：窥(kui)；et拼音首字母：恶(e)徒(tu)",
            "memorize": "嘘！有个恶徒在窥视不安静的教室"
        }
    }
    ```
2. memorize字段结尾的中文句号大部分情况下都不能写
3. 词性顺序：n. & v.；adj. & adv.
